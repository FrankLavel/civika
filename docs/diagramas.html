Diagramas de ConectaMich

Casos de uso, arquitectura de componentes, modelo entidad–relación y flujo de datos de la app ciudadana de reportes urbanos para la zona conurbada Morelia–Tarímbaro.

React Native · Expo Supabase (Auth · Postgres · Storage) Google Maps SDK Expo Push → FCM
01

Diagrama de casos de uso

Actores (monigotes) y casos de uso (óvalos) dentro de la frontera del sistema, unidos por líneas rectas.

02

Arquitectura de componentes

App móvil (pantallas, sesión, capa de datos y módulos nativos), backend Supabase y servicios externos. Cajas y líneas rectas.

03

Diagrama entidad–relación

Modelo en Postgres. Cada usuario posee sus reportes y sus tokens; las fotos viven en Storage y se referencian desde el reporte.

04

Diagrama de flujo de datos

Actores externos (monigotes), procesos (círculos), almacenes de datos (cajas) y servicios, con flechas rectas etiquetadas.
